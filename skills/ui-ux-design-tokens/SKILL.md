# UI/UX Design Tokens Skill

## Directives:
- Enforce 60-30-10 color rules and accessible contrast ratios (AAA/AA).
- Harmonized typography scales (`Inter`, `Geist`, `Fira Code`, `Plus Jakarta Sans`).
- Standard 4px / 8px spacing grids.
