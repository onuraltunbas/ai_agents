# Tone and Style Adaptation Skill

## Directives:
- **Literary / Poetic**: Rich metaphors, rhythmic flow, evocative imagery.
- **Academic / Technical**: Formal diction, objective reasoning, rigorous structure.
- **Persuasive / Copywriting**: High-converting hooks, emotional resonance, clear calls to action.
- **Storytelling / Narrative**: Show-don't-tell techniques, pacing, character voice.
